# 术语表

## 音频接口

**I2S** 是芯片之间传数字音频的总线，一条时钟线加一条帧同步线加一到两条数据线。ESP32-S3 有两个 I2S 控制器，代码里用 `I2S_NUM_AUTO` 让驱动自己挑一个空闲的。

**标准模式（Philips 模式）** 是 I2S 最常见的时序格式，左右声道在一根数据线上交替传输，由帧同步信号区分。

**BCLK** 位时钟，每个数据位一个脉冲。**LRC**（也叫 WS）帧同步，高低电平分别代表左右声道。**DIN / DOUT** 是数据方向，从 ESP32 看出去叫输出，收进来叫输入。**MCLK** 主时钟，MAX98357 和 INMP441 都不需要。

**槽模式** 决定数据线上一帧传几个声道。`I2S_SLOT_MODE_MONO` 只取一个声道，`STEREO` 左右都取。**数据位宽** 是每个槽的比特数，麦克风用 32 位槽，功放用 16 位。

**24 位左对齐** 是 INMP441 的输出格式：它给 24 位有效数据，但塞在 32 位槽的高位，低 8 位是空的，所以读出来要右移 8 位。

**auto_clear** 是 I2S 发送通道的选项，打开后在没数据可发时输出静音，而不是重复上一帧。

## 灯与外设

**RMT** 是 ESP32 的遥控外设，本质是一段可编程的脉冲序列发生器，能精确控制每个电平持续多少个时钟周期。驱动 WS2812 这类单总线器件正好合适。

**RMT encoder** 是把字节流翻译成 RMT 脉冲序列的组件。这里用 `rmt_bytes_encoder`，配置里给出 0 码和 1 码各自的高低电平时长即可。

**WS2812** 是一颗把控制电路和 RGB 三色 LED 封在一起的灯珠，数据线单线串联，每颗灯吃掉 24 位数据（8 位绿、8 位红、8 位蓝），所以顺序是 **GRB** 而不是 RGB。

**归零码** 指 WS2812 用高低电平的持续时间比例表示 0 和 1，而不是电平高低本身。

## 信号度量

**RMS** 均方根，衡量一段信号的等效幅度，比直接取峰值更能反映听感上的响度。

**dBFS** 相对满量程的分贝值，0 dBFS 是能表示的最大幅度，负得越多表示越安静。计算方式是 `20·log10(幅度 / 满量程)`。麦克风满量程取 2^23，因为它给的是 24 位有符号数。

**gamma 曲线** 在这里指对归一化后的音量再做一次幂运算。人眼对亮度的感知不是线性的，不加这一步，很轻的声音也会让灯显得挺亮。

## 芯片与内存

**PSRAM** 是伪静态随机存储器，容量比内部 SRAM 大得多，通过 SPI 接口访问。**Octal SPI** 指 8 线接口，比 **Quad SPI** 的 4 线带宽更高。模组名 **N16R8** 里的 16 是 16 MB Flash，8 是 8 MB PSRAM。

Octal PSRAM 占用了 GPIO33 到 37，Quad Flash 占用了 GPIO26 到 32，所以这些脚在排针上虽然看得见但不可用。

**strapping 脚** 是芯片上电瞬间会被采样的引脚，电平决定启动模式、Flash 电压等。GPIO0、3、45、46 属于这一类，外接电路不能在上电时把它们强拉到错误电平。

## ESP-IDF 与 FreeRTOS

**component** 是 ESP-IDF 的代码组织单位，每个组件有自己的 `CMakeLists.txt`，声明它提供哪些头文件、依赖谁。`main` 本身也是一个组件。

**sdkconfig** 是构建配置的持久化文件，由 `sdkconfig.defaults` 加 menuconfig 的选择生成。它不进版本库，因为不同机器重新构建时会重新生成。

**Kconfig** 是定义 menuconfig 菜单项的语言。工程里的 `Kconfig.projbuild` 就用来定义 LED 类型、GPIO 号这些可配置项。

**app_main** 是应用的入口函数。它返回后 FreeRTOS 调度器接管，所以常驻逻辑要放进任务里。

**task** 是 FreeRTOS 的执行单元，创建时指定栈大小、优先级和入口函数。**vTaskDelay** 让任务睡眠指定 tick 数，是任务主动让出 CPU 的标准做法，也是避免看门狗超时的关键。

**日志 TAG** 是 `ESP_LOGI` 这类宏的第一个参数，串口输出里以 `I (时间戳) TAG:` 的形式出现，用来区分不同模块的输出。
