# 拍手回声机

对着板子拍一下手，它会回你一声。三个模块一起工作：麦克风听拍手，六轴传感器决定回哪个音，功放发声，RGB 灯同时反映环境音量并在拍手瞬间闪亮。

## 接线

| 模块 | 引脚 |
|---|---|
| INMP441 麦克风 | L/R→GND、WS→G4、SCK→G5、SD→G6、VDD→3V3 |
| MAX98357 功放 | LRC→G16、BCLK→G15、DIN→G7、GAIN→GND、SD→3V3 |
| MPU6050 六轴 | SDA→G8、SCL→G9、VCC→3V3、GND→GND |
| WS2812 灯 | 板载，GPIO48 |

麦克风和功放分属两组独立的 I2S 引脚，所以工程里用了两个 I2S 控制器：麦克风占一个做接收，功放占一个做发送。这是能同时录音和放音的前提。

## 行为

拍手检测看的是音量的**跳变**而不是绝对值：当前窗口超过 0.65、比上一窗口高出 0.2 以上、且距上次拍手超过 180 ms，才算一次拍手。这样能避开说话声和持续噪声。触发后扬声器播放一个 250 ms 衰减的正弦音，听起来像被「回应」而不是一声硬邦邦的蜂鸣。

音高由板子的倾角决定，静止平放是 523 Hz，向前倾到 40° 是 880 Hz，中间按五声音阶取五档（523 / 587 / 659 / 784 / 880）。倾角由低通滤波后的重力向量算出，所以晃动不会让音高乱跳。

灯的亮度平时跟随环境音量（和 `03_mic_level` 一致），拍手瞬间强制到最亮，然后按每帧 0.9 的系数衰减，约 250 ms 回到环境水平。

## 运行

```powershell
.\tools\build.ps1   -Project 05_clap_echo
.\tools\flash.ps1   -Project 05_clap_echo -Port COM4
.\tools\monitor.ps1 -Project 05_clap_echo -Port COM4
```

串口每 40 次循环打一行状态，拍手时额外打一行：

```
I (8123) CLAP: level=0.28  brightness=20  tilt=3 deg  note=2
I (9450) CLAP: clap  level=0.94  tilt=3 deg  note=2  659 Hz
```

## 调参

都在 `main/main.c` 顶部：

| 常量 | 默认 | 作用 |
|---|---|---|
| `CLAP_LEVEL` | 0.65 | 判定为拍手的最低音量，环境吵就调高 |
| `CLAP_RISE` | 0.20 | 要求的最小跳变幅度，调小更容易触发 |
| `CLAP_REFRACTORY_MS` | 180 | 两次拍手的最小间隔 |
| `s_notes[]` | 五声音阶 | 改音高，加长数组就能加档 |
| `TILT_RANGE_DEG` | 40 | 倾多少度走完全部音档 |
| `FLASH_DECAY` | 0.90 | 拍手闪光的衰减速度，越小灭得越快 |

音频侧在 `main/audio_out.c`：`TONE_FRAMES` 是音符长度，`AMPLITUDE` 是数字音量。麦克风灵敏度在 `main/mic_level.c` 的 `MIC_FLOOR_DB` / `MIC_CEIL_DB`。

## 已知限制

环境噪声底偏高的房间里，`level` 平时就在 0.2~0.45 之间，这时灯的底亮度不为零，属于正常。如果拍手识别不灵，先把 `monitor` 打开观察安静时的 `level`，再决定是调 `CLAP_LEVEL` 还是调麦克风的归一化窗口。

传感器如果初始化失败（比如接线松了），程序不会停，所有拍手都回同一个 523 Hz，串口会打印接线提示。
